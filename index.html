    The physics — live formulas

    The card matching your current mode is highlighted. Values update in real time as you adjust sliders.

    Horizontal throw
    x = u·t  ·  y = h − ½g·t²

    Fired horizontally, the object accelerates only downward. Horizontal velocity stays constant — only gravity changes the vertical part.

    Key idea: tfall = √(2h/g), Range = u·tfall — the fall time is set by h alone.

    Angled launch
    R = u²·sin(2θ)/g

    Range is maximised at θ = 45°, since sin(2θ) is largest there (sin 90° = 1).

    Key idea: Range ∝ u² and varies with sin(2θ). Angles θ and (90°−θ) give the same range.

    From a height
    t = (vy0 + √(vy0² + 2gh))/g

    Launching from a height gives extra fall time, so the projectile travels further than the same shot from the ground.

    Key idea: Throw from a cliff and you get extra range for free — the ground is now further below you.

    Watch out: Air resistance is ignored in this simulation. In real life, air drag slows the projectile and shortens the range.
